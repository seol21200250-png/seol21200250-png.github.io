1. 수집 항목과 목적

서비스항목목적
사주풀이 리포트이름(닉네임), 성별, 생년월일(양·음력), 출생시간, 질문 내용, 이메일, 결제 정보(결제대행사 처리)사주 계산, 리포트 작성·발송, 결제·환불, 고객 문의 대응
일간 계산기생년월일 (이용자 브라우저에서만 계산, 서버로 전송·저장하지 않음)일간 표시

2. 보유 및 파기

  • 리포트 작성 정보(생년월일·출생시간·질문)와 리포트 파일: 발송 후 30일 동안 재발송·문의 대응을 위해 보관한 뒤 파기합니다.
  • 결제·환불 기록: 「전자상거래법」에 따라 5년 보관합니다. (결제대행사 보관 포함)
  • 이용자가 삭제를 요청하면 법령상 보관 의무가 있는 정보를 제외하고 지체 없이 파기합니다.

3. 처리 위탁

  • ㈜토스페이먼츠: 결제 처리
  • 이메일 발송 서비스: 리포트 발송

4. 개인정보의 국외 이전

리포트 작성과 자동 처리를 위해 아래와 같이 개인정보가 국외로 이전됩니다. 이용자는 동의를 거부할 수 있으나, 이 경우 서비스 이용이 어렵습니다.

  • Anthropic, PBC (미국): AI 리포트 작성 보조 / 성별, 생년월일·출생시간에서 계산한 사주 정보, 질문 내용, 닉네임 / 서비스 제공 시 암호화 통신으로 전송 / 처리 목적 달성 후 해당 사의 정책에 따라 보관·삭제
  • GitHub, Inc. (미국): 리포트 생성 작업 서버 / 위 항목과 이메일 / 작업 실행 시 전송 / 작업 기록은 회사가 정한 기간 후 삭제

5. 유튜브 업로드 도구 (‘사주숏츠’)

운영자 본인의 유튜브 채널에 영상을 올리기 위한 내부 도구로, YouTube Data API의 동영상 업로드 권한만 사용하며 시청자 등 다른 사람의 정보를 수집하지 않습니다. 앱이 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다. 권한 철회: Google 계정 → 타사 앱 액세스
