야화 사주

개인정보처리방침

시행일: 2026년 11월 10일

1. 앱 소개

‘사주숏츠’(이하 “앱”)는 야화 사주 운영자가 본인의 유튜브 채널에 직접 제작한 운세 숏츠 영상을 자동으로 업로드하기 위해 만든 내부용 자동화 도구입니다. 일반 이용자에게 제공되는 서비스가 아니며, 다른 사람의 계정으로 로그인하지 않습니다.

2. 사용하는 Google 사용자 데이터

  • 권한 범위: YouTube Data API의 youtube.upload (동영상 업로드) 한 가지
  • 사용 목적: 운영자 본인 채널에 영상과 제목·설명·태그를 업로드
  • 앱은 시청자, 구독자, 댓글 등 다른 사람의 개인정보를 수집·조회·저장하지 않습니다.

3. 보관 및 보호

업로드에 필요한 인증 토큰은 운영자의 GitHub 저장소 암호화 저장소(Secrets)에만 보관되며, 외부에 공개하거나 제3자에게 제공·판매하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요건 포함)을 준수합니다.

5. 권한 철회

언제든지 Google 계정 → 타사 앱 액세스에서 ‘사주숏츠’의 접근 권한을 삭제할 수 있습니다.
